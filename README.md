# ishwacha

Мой личный сайт-визитка и одновременно место для баловства и экспериментов.

Здесь живут галерея работ, информация о коммишенах и всё, что хочется попробовать
в вебе: новые анимации, странные переходы, мелкие интерактивные штуки, которые
некуда больше приткнуть. Сайт не претендует на роль серьёзного продукта —
это витрина и песочница в одном флаконе.

**Сайт:** https://hwacha2.github.io

> A personal portfolio and a playground: art gallery, commission info, and a
> place to try out web experiments. Russian is the main language, the site is
> also available in English.

## Что внутри

| Страница | Что там |
|---|---|
| `/` | Главная: приветствие, галерея работ, моды, соцсети, лента из Telegram |
| `/commissions` | Прайс, статус слотов, правила и форма брифа |
| `/privacy` | Политика конфиденциальности и обработки данных |
| любой другой адрес | Симпатичная 404 вместо пустого экрана |

Основной канал связи — Telegram, Discord — вторичная ссылка.
Личный чат: [@hwaaacha](https://t.me/hwaaacha), новости: [@ishwacha](https://t.me/ishwacha).

## Стек

- **Vue 3** (`<script setup>`) + **Vite**
- **vue-router** с ленивой загрузкой страниц
- Чистый CSS, без UI-фреймворков; из Bootstrap подключён только CSS-сброс
- Своя микро-i18n: RU / EN, переключение в меню навигации
- Хостинг — **GitHub Pages**, деплой через GitHub Actions
- Статус слотов — **Cloudflare Worker** (см. `worker/`), бэкенда для заявок нет

## Как запустить

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # сборка в dist/
npm run preview    # посмотреть собранное
```

Полезные проверки:

```bash
npm run check:i18n   # ключи ru/en совпадают, мёртвых нет
npm run images       # пересобрать картинки из masters/ в public/ (Python + Pillow)
```

## Структура

```
src/
  views/          страницы (Home, Commissions, Privacy, NotFound)
  components/     галерея, модалки, меню, лента Telegram, форма брифа
  composables/    язык, черновик формы, брейкпоинты
  data/           контент и настройки: pricing.js, config.js, homeData.js
  locales/        ru.json / en.json
  assets/         стили и кнопки соцсетей
worker/           Cloudflare Worker: /api/slots, вебхук Telegram
masters/          исходники изображений (не отдаются в сборку)
public/           оптимизированные webp, шрифты, favicon
scripts/          check-i18n, optimize-images, spa-fallback
```

## Как менять контент

- **Цены** — только в `src/data/pricing.js`. Это единственный источник правды,
  тексты страниц подхватывают значения оттуда.
- **Ссылки и контакты** — `src/data/config.js` (Telegram, канал, Discord, Boosty, e-mail).
- **Тексты** — `src/locales/ru.json` и `src/locales/en.json`. Ключи должны совпадать:
  после правок запускайте `npm run check:i18n`.
- **Картинки** — положить исходник в `masters/`, затем `npm run images`;
  готовые webp окажутся в `public/`.

## Форма заявки

Заявка никуда не отправляется с сайта: форма собирает бриф прямо в браузере,
копирует его в буфер обмена и открывает Telegram с готовым `?text=`. Дальше —
обычный диалог. Поэтому у сайта нет базы заявок и нет серверной части,
которой можно было бы доверять персональные данные.

Статус слотов берётся с воркера (`GET /api/slots`, кэш около минуты).
Если воркер молчит, страница честно показывает «Статус недоступен»
и предлагает проверить ещё раз или заглянуть в канал.

## Деплой

Пуш в `main` запускает `.github/workflows/deploy.yml`: сборка → GitHub Pages.
Ничего вручную заливать не нужно. `npm run deploy` — старый локальный способ
через `git subtree`, оставлен на всякий случай.

## Мелочи, которые тут специально

- Hover-эффекты завёрнуты в `@media (hover: hover)`: на тач-устройствах они
  не применяются и не залипают после тапа.
- Вместо hover на мобилке — короткое «утапливание» кнопки при нажатии.
- На `/commissions` есть мобильная плашка с цветным торцом-статусом:
  тап возвращает наверх к шапке. Позиция скролла переживает перезагрузку.
- Ничего не анимируется, если пользователь включил `prefers-reduced-motion`.
